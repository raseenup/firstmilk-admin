Company Admin Portal — Role-Based Access Control (RBAC) Matrix

Granular permissions across functional modules ensuring least-privilege access and operational efficiency.

• Super Admin Ultimate system authority. Manages global configurations, core security, user roles, system infrastructure, and can override any action.
• Operations Manager Oversees day-to-day business logistics, service catalogues, inventory, booking/order pipelines, and scheduling.
• Finance Controls financial ledgers, billing, tax compliance (e.g., VAT/ZATCA configurations), invoicing, payouts, and refund authorizations.
• Customer Support Handles user assistance, support ticketing, viewing user directories, and managing minor dispute escalations.
