# Admin portal v11

Deploy the matching dairy-backend v11 change first. Read its UPGRADE_V11.md.

Overview owns sign out and dark-mode/sound settings. The new Drivers workspace
contains incentive instructions and review, date-prioritized coordinate route
planning with admin-only contribution estimates, failed-attempt reports, driver
performance/reviews and private document expiration/downloads. Accounts controls
configure base/peak pay, record verified earnings/deductions and approve/reject
payout requests, then record actual external payment with its reference.

Super Admin can designate individual driver managers and payout approvers from
Invitations. The two permissions are separate. Configure depot coordinates,
product/travel costs and driver pay rates before relying on those estimates.
No fabricated ratings, pay or profit is shown for missing data. The route map
is a local coordinate estimate, with links for road directions; it does not use
live traffic or guarantee a global profit optimum.

New assets: workspace.js/css and workforce.js/css. No build step or paid service
is introduced. Existing modules and role checks remain. Main refreshes are
batched, visible revision polls run every 1.5 seconds, and the heavier Drivers
data is fetched only while that workspace is selected.
